
# Tecno Nova

Aplicación desarrollada como proyecto formativo SENA - ADSO (Ficha 3235887).

## Descripción
Tecno Nova es una aplicación de e-commerce con frontend en HTML/CSS/JavaScript
y backend planeado en Node.js + Express + MySQL.

## Control de versiones
Este repositorio documenta el flujo de trabajo con Git:
- git init: inicialización del repositorio local
- git add: preparación de cambios (staging)
- git commit: registro de cambios con mensajes descriptivos
- git remote add: conexión con el repositorio remoto en GitHub
- git push: envío de cambios al repositorio remoto
- git pull: actualización del repositorio local desde el remoto
